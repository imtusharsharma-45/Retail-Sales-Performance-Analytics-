# Superstore Sales Analysis Project

## Project Objective
The objective of this project is to analyze Superstore sales data and identify business insights related to sales performance, profitability, customer behavior, regional trends, and discount impact.

## Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- VS Code

## Key Insights
- Technology category has highest sales and profit
- Phones have highest sales
- Copiers have highest profit
- Tables generate highest losses
- West region performs best
- Discounts reduce profitability

## Project Structure
- Data Cleaning
- Exploratory Data Analysis
- Business Insights
- Data Visualization
